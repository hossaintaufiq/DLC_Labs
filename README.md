# DLC_Labs - Digital Logic Circuits Lab Resources

This repository contains all the necessary resources for **Digital Logic Circuits (DLC)** laboratory work, specifically for **CSE231**. The resources include detailed lab manuals and a project proposal that will help students and instructors in understanding and executing lab activities effectively.

---

## 📂 Repository Contents

### Lab Manuals
The repository contains comprehensive lab manuals for each experiment in the Digital Logic Circuits course. Below is the list of included manuals:

1. **Lab Manual 01**: Digital Logic Gates and Boolean Algebra  
2. **Lab Manual 02**: Universal Gates  
3. **Lab Manual 03**: Combinational Logic Design I  
4. **Lab Manual 04**: Combinational Logic Design II  
5. **Lab Manual 05**: Binary Arithmetic  
6. **Lab Manual 06**: BCD to Seven Segment Decoder  
7. **Lab Manual 07**: Introduction to Multiplexers  
8. **Lab Manual 08**: Introduction to Flip-Flops  
9. **Lab Manual 09**: Synchronous Sequential Circuits  

Each manual provides step-by-step instructions, theoretical background, and practical exercises for hands-on learning.

---

### Project Proposal
The repository also includes:
- **Project Proposal (DOCX)**: Editable document format for the project proposal.
- **Project Proposal (PDF)**: Finalized project proposal in PDF format.

These documents can serve as a reference for project planning and execution in the DLC course.
